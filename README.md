# moysklad_mosinprss

Задание 01.10.2026

Надо создать Rest API для работы с товарами аналогичный Remap Api 1.2 

1. Для этого надо создать таблицу product

**Поля таблицы**

- **name** — наименование товара (обязательно).
- **description** — описание (необязательно).
- **uom** — единица измерения. Чаще всего используют `BASE` (базовая единица). Чтобы получить список доступных единиц, можно сделать `GET /api/remap/1.2/entity/uom`.
- **price** — цена (число, без указания валюты).
- **currency** — валюта. Для рублей используют ссылку на сущность `RUB`. Список валют можно получить запросом `GET /api/remap/1.2/entity/currency`.
- **archived** — флаг архивации: `false` — активный товар, `true` — в архиве.

2. **Поля таблицы**

- **name** : "ABC-123-BLK-M",
- **article** — артикул (удобно для сопоставления с внешними системами).
- **attributes** - таблица с аттрибутами, два поля наименование аттрибута и значение  например: : {
"color": "чёрный",
"size": "M"
}

Таблицу нужно создать с помощью инструментов миграции, на выбор: liquibase, flyway и тд.

3. Также нужно создать таблицы для справочников единиц измерений и валют, над схемой бд надо подумать и предложить решение перед реализацией. 
Значения для справочников нужно получать по Remap API 1.2 при старте приложения и обновлять с помощью шедулера с периодичностью один час, например.

**CRUD-операции с товарами надо сделать аналогичный Remap API**

| Действие | Метод | Эндпоинт в REMAP                     | Комментарий |
| --- | --- |--------------------------------------| --- |
| Получить список товаров (с пагинацией и фильтрами) | `GET` | `/api/remap/1.2/entity/product`      | Поддерживает параметры: `limit`, `offset`, `filter`, `expand` и др. |
| Создать товар | `POST` | `/api/remap/1.2/entity/product`      | В теле — JSON с полями товара. Можно пакетно (массивом). |
| Получить товар по ID | `GET` | `/api/remap/1.2/entity/product/{id}` | Возвращает полную карточку товара. |
| Обновить товар | `PUT` | `/api/remap/1.2/entity/product/{id}` | Передаётся весь объект или его части (зависит от логики API). |
| Частичное обновление (PATCH-стиль) | `PATCH` | `/api/remap/1.2/entity/product/{id}` | Часто используют для точечных правок (цена, остаток и т. п.). |
| Удалить товар (архивировать) | `DELETE` | `/api/remap/1.2/entity/product/{id}` | В «МойСклад» удаление обычно означает архивацию (`archived: true`). |

**Авторизация**

Все эндпоинты должны поддерживать авторизацию, логин и пароль пока берем из конфигов приложения

```http
Authorization: Basic <base64(login:password)>
```

**Стек приложения**: Java, Spring Framework, Hibernate, PostgreSQL, Docker, TestContainers, JUnit 5, Maven
