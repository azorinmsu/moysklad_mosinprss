# Шаблон тестового сценария

Скопируйте блок в `docs/testing/test-scenarios.md`. На этом этапе код теста не пишется.

```text
## TC-<ОБЛАСТЬ>-<НОМЕР>. <имя>

- Уровень: unit | integration | contract | e2e | load | concurrency | fault-injection
- Режим МойСклад: mock | real | не участвует
- Связанные FR и AC:
- Предусловия и фикстуры:
- Управляющие команды заглушки (если нужны):
- Шаги:
  1.
- Ожидаемый наблюдаемый результат:
- Проверка идемпотентности (если сценарий повторяемый):
- Что не должно измениться:
- Очистка тестового аккаунта (для real):
```

Для `real` в шагах нет боевого токена и нет рабочего аккаунта. Для contract указано, какие поля JSON сравниваются, а какие пропускаются (`id`, временные ссылки, порядок неупорядоченного краткого отчёта).
