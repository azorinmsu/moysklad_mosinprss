# Шаблон бизнес-процесса

Скопируйте блок в `docs/business/business-processes.md` для каждого процесса из задания.

```text
## BP-<НОМЕР>. <имя процесса>

- Цель:
- Инициатор:
- Другие участники:
- Границы систем: витрина / backend / база магазина / МойСклад / заглушка оплаты
- Предусловия:
- Результат успеха:
- Результат отказа:
- Источник истины данных, которые процесс меняет:
- Допустимая длительность и допустимая задержка данных:

### Основной поток
1.

### Развилки
| Условие | Ветка | Наблюдаемый результат |
|---|---|---|

### Ошибки и повторы
| Сбой | Повтор безопасен? | Компенсация | Что видит человек |
|---|---|---|---|

### Данные
| Данные | Откуда | Куда | Ключ сопоставления |
|---|---|---|---|

### Связанные требования и диаграммы
- FR:
- BPMN:
- Sequence:
- ADR:
```

Процесс без ветки отказа считается незавершённым. Ссылка на диаграмму не заменяет таблицу ошибок.
