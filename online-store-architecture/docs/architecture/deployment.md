# Развёртывание

Диаграмма: `docs/diagrams/c4/deployment.puml`.

Покажите будущий учебный стенд, без обязательного файла Compose на этом этапе. Если Compose всё же прикладывается, он не содержит токена.

## Узлы

- frontend;
- backend;
- база данных магазина;
- заглушка Remap API — предоставленный процесс `remap-stub` на порту `8088`, студент описывает только адрес и режим, не устройство сервиса;
- заглушка оплаты;
- секретное хранилище или файл окружения вне Git;
- МойСклад как внешняя система для режима `real`.

Узлы брокера, кэша и системы метрик появляются здесь только после ADR.

## Переключение режима

Приведите конфигурацию `mock` и `real` и укажите, какой процесс какой URL видит. Доменный код URL не выбирает.

Токен в режиме `real` обязателен и попадает в процесс только из окружения. Пример в репозитории показывает имя переменной `MOYSKLAD_TOKEN` без значения.

## Сеть

Кто инициирует соединение:

- магазин → Remap API или заглушка;
- МойСклад → URL вебхука магазина;
- покупатель → frontend и публичное API;
- администратор → административное API.

Для вебхука укажите, чем приёмник отличается от публичного API покупателя.

## Что переживёт перезапуск

Какие хранилища содержат заказ, ключ идемпотентности и непрочитанную исходящую работу. Что потеряется, если хранить это только в памяти процесса.
