# Ошибки внешнего API

Политика для адаптера Remap и для приёмника вебхуков. Доменные сообщения покупателю задаются отдельно: ему не показывают код 17003 сырым текстом учёта, если только вы сознательно не выбрали иначе.

Отдельно: повтор создания использует `syncId` или другой записанный механизм и не является слепым вторым `POST`. Повтор 429 не учащает запросы. Circuit breaker, если он есть, ссылается на ADR и говорит, что витрина делает, пока цепь разомкнута.

Классификация для покупателя: «попробуйте ещё раз», «заказ принят и уточняется», «отказано по наличию», «отказано по данным оплаты». Каждая фраза связана со строкой таблицы.
