# Синхронизация

Связанные процессы: BP-01 и BP-02. Связанные ADR: механизм синхронизации, хранение каталога, источники истины.

## Каталог

Опишите первичную загрузку, инкремент, архив, цены, изображения, ошибку страницы, простой дольше цикла.

Сравните в этом файле, даже если выбор уже записан в ADR:

| Подход | Что обнаруживает | Что теряет | Цена в запросах на 100 000 позиций | Вывод |
|---|---|---|---|---|
| Опрос по `updated` | | | | |
| Вебхуки сущностей | | | | |
| Смешанная схема и полная сверка | | | | |

Для изображений опишите, где оказывается байтовое содержимое, которое отдаёт витрина, и почему публичная страница не зависит от минутного `downloadHref`.

## Остатки

Опишите выбранный отчёт, `stockType`, склады, период, перекрытие интервалов, полную сверку не реже раза в сутки, поведение `changedSince` после простоя дольше 24 часов, запаздывающий пересчёт.

Допустимая задержка остатка: число и последствие для покупателя, который видит устаревшее количество.

Правило продажи при расхождении локальной проекции и отчёта: кто блокирует оформление.
