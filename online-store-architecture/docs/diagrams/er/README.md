# Диаграммы ER

Три уровня соответствуют `docs/database/data-model.md`. Имена сущностей совпадают с физической моделью на третьей диаграмме.

| Файл | Уровень | Что показать |
|---|---|---|
| `conceptual.puml` | Концептуальный | Сущности и связи без типов столбцов. Витрина и учёт различимы |
| `logical.puml` | Логический | Атрибуты, обязательность, уникальность |
| `physical.puml` | Физический | Таблицы, PK, FK, уникальные ограничения |

На физическом уровне у связи с МойСклад виден внешний идентификатор там, где он хранится. Деньги подписаны единицей измерения и точностью. Каскадное удаление, если оно есть, отмечено на связи и совпадает с правилом в модели данных.

Не требуется изображать все таблицы подсказки. Требуется изобразить все таблицы, которые вы оставили в модели.
