# Диаграммы последовательности

PlantUML или Mermaid. Участники называются одинаково с контейнерами C4.

| Файл | Сценарий |
|---|---|
| `checkout-success.puml` | Успешное оформление |
| `checkout-insufficient-stock.puml` | Недостаточное количество |
| `checkout-concurrent.puml` | Два покупателя и последняя единица |
| `customerorder-create.puml` | Создание заказа в МойСклад |
| `customerorder-timeout.puml` | Таймаут создания, документ мог сохраниться |
| `webhook-redelivery.puml` | Повтор с тем же `requestId` |
| `cancel-paid.puml` | Отмена оплаченного заказа |
| `cancel-vs-shipment.puml` | Одновременные отмена и отгрузка |
| `moysklad-unavailable.puml` | Недоступность МойСклад |
| `sync-recovery.puml` | Восстановление синхронизации |

На диаграмме отказа видны: локальная транзакция, внешний вызов, что уже записано до вызова, повтор, компенсация и ответ покупателю или администратору. Успешный сценарий эти элементы не заменяет.

Для таймаута создания покажите оба продолжения: документ найден по `syncId` или по локальному ключу и документ не найден. Для вебхука покажите ответ 200 или 204 до тяжёлой работы и вторую доставку того же `requestId`.
