# Шаблон ADR

Рабочий шаблон лежит в [`../../templates/adr-template.md`](../../templates/adr-template.md). Записи создаются рядом с этим файлом: `ADR-001-....md` и далее.

Обязательный набор названий (формулировку можно уточнить, смысл сохранить):

1. Выбор архитектурного стиля.
2. Выбор модели хранения каталога.
3. Выбор механизма синхронизации.
4. Выбор источников истины.
5. Выбор механизма резервирования.
6. Обеспечение идемпотентности.
7. Обработка распределённых транзакций.
8. Обработка конкурентного доступа.
9. Архитектура интеграции с МойСклад.
10. Архитектура заглушки Remap API.
11. Обработка ошибок внешнего API.
12. Восстановление согласованности данных.

Пустые ADR заранее не заведены: запись появляется тогда, когда решение принято. Список выше — обязательство по составу, а не заготовки с выбранным вариантом.
