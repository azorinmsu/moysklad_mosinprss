# Сквозные критерии приёмки

Сюда попадают критерии, которые проходят через несколько требований или через внешнюю систему. Остальные Given / When / Then остаются в функциональных требованиях.

Для каждой строки: идентификатор `AC-<ПРОЦЕСС>-<НОМЕР>`, ссылки на FR, предусловие, действие, наблюдаемый результат в витрине, в локальной базе и в учёте (или в заглушке). Если один из трёх контуров не меняется, это написано прямо.
