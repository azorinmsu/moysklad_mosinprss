# Индексы

Каждый индекс связан с запросом. Индекс «на всё» не нужен.

Обязательно разберите запросы:

- выдача категории и поиск по каталогу на объёме 100 000 карточек;
- карточка по локальному идентификатору и по внешнему UUID;
- остаток по складу и позиции ассортимента;
- корзина покупателя;
- заказы покупателя по дате;
- поиск заказа по ключу идемпотентности и по `syncId` или внешнему id;
- выборка зависших заказов по состоянию и времени обновления;
- выборка непроведённой исходящей работы синхронизации;
- приём вебхука: есть ли уже такой `requestId`.
